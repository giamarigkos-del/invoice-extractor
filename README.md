# Invoice Extractor

Εργαλείο εξαγωγής δομημένων δεδομένων από τιμολόγια και αποδείξεις (PDF/εικόνα → JSON → βάση δεδομένων), με χρήση Gemini AI για οπτική ανάγνωση (OCR) και εξαγωγή πεδίων.

Μέρος μιας σειράς εργαλείων πάνω σε Cloudflare Workers — γενικός/προσαρμόσιμος πυρήνας, με σκέψη για πιθανή μελλοντική χρήση από μικρά λογιστικά γραφεία ή freelancers.

## Τι κάνει

1. Ανεβάζεις ένα τιμολόγιο/απόδειξη (PDF, PNG ή JPG)
2. Το αρχείο αποθηκεύεται στο Cloudflare R2
3. Το Gemini διαβάζει το αρχείο και εξάγει: προμηθευτή, ΑΦΜ, αριθμό τιμολογίου, ημερομηνία, νόμισμα, υποσύνολο, ΦΠΑ, τελικό σύνολο, και όλα τα επιμέρους είδη (line items)
4. Γίνεται αυτόματος έλεγχος συνέπειας ποσών (subtotal + tax = total) και έλεγχος πιθανού διπλότυπου
5. Τα δεδομένα αποθηκεύονται στη Cloudflare D1 (SQLite), με δυνατότητα προβολής, επεξεργασίας και διαγραφής

## Stack

- **Runtime:** Cloudflare Workers (JavaScript)
- **Βάση δεδομένων:** Cloudflare D1 — πίνακες `invoices` και `line_items`
- **Αποθήκευση αρχείων:** Cloudflare R2
- **AI εξαγωγή:** Gemini API (`gemini-3.8-flash`, με αυτόματο fallback σε `gemini-3.6-flash` σε περίπτωση 503)

## Endpoints

| Method | Path | Περιγραφή |
|---|---|---|
| `GET` | `/health` | Έλεγχος λειτουργίας του service |
| `POST` | `/upload` | Ανέβασμα αρχείου, εξαγωγή δεδομένων, αποθήκευση |
| `GET` | `/invoices` | Λίστα όλων των τιμολογίων με ενσωματωμένα τα line items |
| `PATCH` | `/invoices/{id}` | Ενημέρωση πεδίων ενός τιμολογίου (χειροκίνητη διόρθωση) |
| `DELETE` | `/invoices/{id}` | Διαγραφή τιμολογίου και των line items του |
| `GET` | `/invoices/{id}/file` | Προβολή/λήψη του πρωτότυπου αρχείου από το R2 |

## Τοπική εκτέλεση

```bash
npm install
wrangler dev
```

Χρειάζεται ένα `.dev.vars` αρχείο με:
```
GEMINI_API_KEY=...
```

Άνοιξε το `public/test.html` στον browser για δοκιμαστικό UI (upload + λίστα + επεξεργασία).

## Γνωστοί περιορισμοί

- Ο έλεγχος διπλότυπου βασίζεται σε `invoice_number` + `total_amount`. Παραστατικά χωρίς αριθμό τιμολογίου δεν ελέγχονται για διπλότυπο.
- Το `workspace_id` είναι προσωρινά σταθερό (`"default"`) — δεν υποστηρίζεται ακόμα multi-tenant λειτουργία.
- Η εξαγωγή μέσω AI δεν είναι 100% αλάνθαστη (π.χ. διαφορετική μορφοποίηση ονόματος προμηθευτή σε διαφορετικά περάσματα) — γι' αυτό υπάρχει δυνατότητα χειροκίνητης διόρθωσης μέσω `PATCH`.
